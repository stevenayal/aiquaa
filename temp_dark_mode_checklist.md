# Cambios de Dark Mode para Checklist

## Patrón a aplicar en /labs/checklist:

1. Importar useTheme
2. Contenedor principal: bg-brand-light → bg-slate-900 (dark)
3. Links: text-brand-muted → text-slate-400 (dark)
4. Títulos: text-brand-text → text-white (dark)
5. Textos: text-brand-muted → text-slate-300/400 (dark)
6. Cards bg-white → bg-slate-800 (dark)
7. Borders: border-gray-200 → border-slate-600 (dark)
8. Inputs/textareas: bg-white → bg-slate-800, text-gray-900 → text-white (dark)
